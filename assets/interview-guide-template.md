# 半结构化访谈提纲

研究主题：【】  版本：【】  受访者类型：【】  预计时长：【】

## 访谈前

- [ ] 核对筛选条件和匿名 ID
- [ ] 说明研究目的、时长、使用方式、退出权
- [ ] 单独取得录音/拍照许可
- [ ] 主持人与记录员分工

## 开场

“我们希望了解您最近的真实经历，没有标准答案。您可以跳过任何问题或随时结束。研究结果会匿名呈现。请问是否同意开始？是否同意录音？”

## 热身与背景

1. 请简单介绍您与【消费/采购/经营/配送场景】的关系。
2. 最近一次接触【案例企业/品类/服务】是什么时候、在哪里？

## 最近一次真实行为

1. 请从头讲讲最近一次【选择/购买/使用/配送/投诉】经历。
2. 当时有哪些选项？您如何决定？
3. 谁参与了决定？使用了哪些渠道或信息？
4. 哪一步最顺利？哪一步最困难？请举具体例子。

## 痛点、机制与替代

1. 这个问题多久发生一次？造成了什么实际影响？
2. 您以前如何处理？为何有效或无效？
3. 您是否改选竞品、其他渠道或不行动？触发点是什么？
4. 如果现状不变，您会怎么做？

## 地区与场景

1. 【目标地区】与其他地区/门店/渠道相比有什么不同？
2. 当地价格、交通、商圈、习惯、供应或竞争如何影响您的选择？

## 方案反应（仅在探索完成后）

1. 这个方案在哪种场景下有用？在哪种场景下无用？
2. 您最担心的成本、风险或执行障碍是什么？
3. 要让您相信它有效，需要看到什么行为或结果？

## 反证与收尾

1. 有没有与我们假设完全相反的经历？
2. 还有什么重要内容没有问到？
3. 还有哪些角色值得访谈？
