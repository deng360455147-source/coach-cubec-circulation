# 流通业经营分析报告 Excalidraw 色板

这是主报告的结构图色板。颜色只表达意义，不复制往届作品的成品图。

| 用途 | 填充 | 描边/文字 |
|---|---|---|
| 主流程/核心能力 | `#DCE8F5` | `#1B365D` |
| 外部环境/市场 | `#E8EEF3` | `#52687A` |
| 顾客/价值结果 | `#DDEFE8` | `#2F6B57` |
| 约束/瓶颈 | `#F7E4DE` | `#A14E3A` |
| 方案/行动 | `#F5EEDB` | `#8A6B22` |
| 中性分区 | `#F6F7F8` | `#4B5563` |
| 画布 | `#FFFFFF` | `#1F2937` |

所有图内普通文字在最终Word宽度下不得小于14pt，关键节点、主标签和关键数字使用16pt；不得出现比14pt更小的注释。放不下的口径与说明移到正文或来源注。图片中不放总标题、图号、题注或来源全文。概念关系图可用 `roughness: 1`，精确流程、泳道和度量关系用 `roughness: 0`。除14pt与16pt两档外，优先使用颜色、线宽、留白和位置建立层级。
