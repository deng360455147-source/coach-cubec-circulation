# 调研、证据与方法

## 证据优先级

1. **A 级**：企业年报、公告、招股书、官网可核实信息；国家/地方政府、统计部门、法院或监管机构；正式标准与政策。
2. **B 级**：行业协会、学术论文、权威数据库、可信研究机构；方法和样本透明的行业报告。
3. **C 级**：主流媒体的署名报道、平台公开数据、门店页面和地图信息。
4. **D 级**：用户评论、社交媒体、二手转述；只用于提出线索或展示体验，不单独支撑重大结论。
5. **T 级（一手团队证据）**：访谈、问卷、门店观察、神秘顾客、价格与履约测试。必须保存原始记录、时间、地点、样本和方法。

同一重大结论尽量由至少两类独立证据交叉验证。来源之间冲突时报告口径、期间和利益关系，不选择性隐去。

## 证据台账字段

| 字段 | 要求 |
|---|---|
| 主张 ID | 与正文段落/图表对应 |
| 主张 | 一句可验证陈述 |
| 证据 | 数字、事件、观察或引文摘要 |
| 来源 | 机构、文件/页面、链接或页码 |
| 日期/期间 | 发布日期与数据覆盖期间分开 |
| 地区/业务口径 | 全国、省、市、门店；集团、板块或单品 |
| 证据等级 | A/B/C/D/T |
| 限制 | 缺失、偏差、代理指标、不可比口径 |
| 状态 | 已核实 / 待核实 / 不采用 |

## 一手调研最低规范

### 访谈

- 记录受访者角色、与企业关系、时间、方式、授权范围；匿名时保留可内部复核的编码。
- 使用半结构化提纲，追问行为和具体事件，不只收集态度。
- 不得把模拟访谈或 AI 生成回答写成真人访谈。

### 问卷

- 先定义目标总体、抽样渠道、筛选条件、核心变量和分析计划。
- 报告有效样本量、地区、时间、去重/剔除规则、题项与局限。
- 小样本使用描述性统计，不用伪精确的小数或无依据因果结论。
- 附录保留问卷、编码和必要的汇总计算；删除个人敏感信息。

### 门店/网点观察

- 使用统一观察表：位置、时段、客流代理、品类、价格、库存、服务、动线、数字触点、履约与竞品。
- 至少跨两个时段；若只有一个样本，明确它是案例观察而非地区总体。
- 图片与录音遵守场地规则和隐私要求。

## 按问题选方法

| 研究问题 | 可选方法 | 必需输入 | 常见误用 |
|---|---|---|---|
| 宏观与政策变化 | PESTEL、政策文本编码、趋势分析 | 政策原文、统计序列 | 罗列因素，不解释经营影响 |
| 行业竞争结构 | 五力、战略群组、竞品基准 | 市占、门店/网点、价格、服务指标 | 只凭印象打分 |
| 商业模式机制 | 商业模式画布、价值链、单位经济 | 客户/渠道/收入/成本/资源证据 | 画完画布没有诊断 |
| 地区扩张或布局 | 商圈/网点分析、空间对标、区域聚类 | 地址、覆盖、人口、交通、竞品 | 用全国数据替代本地证据 |
| 顾客选择 | 问卷、访谈、评论编码、顾客旅程 | 样本与原始记录 | 小样本推断总体因果 |
| 运营瓶颈 | 流程图、价值流、排队/库存/履约指标、约束理论 | 流程、时间、成本、服务数据 | 没有指标就宣布瓶颈 |
| 财务与绩效 | 趋势/结构/同业对标、杜邦、单位经济、敏感性 | 可比财报与口径 | 拼接不同期间/板块数据 |
| 根因优先级 | 问题树、5 Why、鱼骨、影响-可控矩阵 | 已验证症状和机制 | 把工具输出当证据 |
| 方案验证 | 试点、前后对照、A/B、情景与敏感性分析 | 基线、目标、测量周期 | 只给增长百分比无计算 |

使用 2–4 个互补方法通常足够。每个方法都要说明“为什么适配、输入是什么、得到什么结论、有什么限制”。“前沿”不等于生僻名称；可复核、能解释问题并支持决策比框架数量更重要。

## 数字与预测规则

- 写清币种、单位、含税/未税、名义/实际、同比/环比、时间范围。
- 将实际值、估计值、情景假设分列。
- 预测至少给基准、保守、乐观三种情景；展示关键假设的敏感性。
- 非上市企业缺少财务数据时，使用公开门店数、客单、价格、履约、员工、坪效代理等，并明确不可用于断言利润。
- 方案收益写计算式，例如：`增量收入 = 覆盖门店 × 日均有效客流 × 转化提升 × 客单价 × 天数`。

## 引用与原创

- 对数据、事实、观点和图表就近引用；参考文献完整列出作者/机构、标题、日期、链接或出版信息、访问日期。
- 改写仍需引用；不要通过同义改写规避查重。
- 记录团队原创贡献：选题、观察、访谈、数据清洗、分析、图表、方案、写作与复核。
- 对 AI 协助保留内部使用记录；最终提交遵守当届规则和学校要求，不能原样提交未经团队核实、补充和实质性重写的 AI 草稿。
