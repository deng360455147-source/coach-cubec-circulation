## 1. 调研阶段目标

调研不是为既定观点找佐证，而是决定：

- 核心矛盾是否真实存在；
- 该矛盾在目标省市如何表现；
- 战略、商业模式、运营、市场和财务之间的机制是什么；
- 哪些方案值得进入报告，哪些应被否决；
- 结论能推广到哪里，不能推广到哪里。

先把中心命题拆成 2–4 个研究目标、3–7 个关键问题和一组可被否定的假设。每个问题都要映射到决策、方法、样本、字段和报告章节。

## 2. 默认混合方法路线

在时间有限的学生竞赛中，优先采用：

```text
案头研究与地区证据地图
  → 门店/网点与竞品快速观察
  → 半结构化访谈探索机制
  → 问卷描述规模与分群（仅在题项成熟后）
  → 补充观察/访谈解释矛盾
  → 证据三角验证与报告交接
```

如果无法接触顾客或门店，缩小结论范围，不用公开评论冒充代表性样本。选择 1–2 个主要方法和必要的补充方法；框架越多不等于调研越强。

### 方法选择表

| 要回答的问题 | 首选方法 | 补充方法 | 不能声称 |
|---|---|---|---|
| 企业战略与经营变化 | 年报/公告/政策/历史事件序列 | 管理者或行业访谈 | 未披露的内部动机 |
| 当地顾客选择与体验 | 访谈、问卷 | 公开评论、现场观察 | 便利样本代表全省 |
| 门店/网点运营瓶颈 | 多时段观察、流程记录 | 员工/合作方访谈 | 单次观察等于长期规律 |
| 竞争位置 | 本地竞品矩阵、价格/服务测试 | 评论与顾客访谈 | 无来源的市场份额 |
| 财务与效率 | 年报、公开经营指标、可比公司 | 代理指标、敏感性 | 非上市企业真实利润 |
| 方案可行性 | 专家访谈、试点设计、情景测算 | 顾客概念测试 | 未试点就承诺提升比例 |

## 3. 案头研究与公开评论

### 案头来源顺序

1. 企业年报、公告、招股书、官网、监管披露；
2. 国家和地方政府、统计局、商务/交通/市场监管部门；
3. 行业协会、标准、论文、方法透明的行业报告；
4. 主流媒体与企业访谈；
5. 地图、门店/网点页面、电商平台、公开评论和社交内容。

对每条记录保存 URL/文件、发布日期、数据期间、地区、业务口径、摘录、用途、证据等级和访问日期。搜索摘要不能替代原页面；无法打开原文时降低置信度。

### 公开评论/VOC 两种模式

- **已有材料模式**：处理团队已有访谈、问卷、评论、投诉、观察或企业反馈。
- **公开来源模式**：从大众点评、美团、地图平台、电商评论、App Store、微博、小红书、抖音、B 站、行业论坛等公开页面收集线索。

采集时同时覆盖不同时间、渠道、星级和细分人群，不只摘负面评论。每条保留匿名 ID、平台、日期、地区/门店、原话、情境、主题、情绪和可能偏差。遵守平台条款；不自动绕过限制，不披露用户名、头像、联系方式等无必要信息。

### VOC 提取字段

- 任务/场景：顾客想完成什么；
- 触发事件：为何这次选择或放弃；
- 痛点与强度：具体发生了什么；
- 期望结果：什么算成功；
- 替代方案：竞品、其他渠道或不行动；
- 原始措辞：用于解释，不作为广告素材；
- 行为与表态矛盾：说法是否与观察/交易行为冲突。

## 4. 访谈

### 设计

- 先定义受访者段：顾客、员工/前员工、供应商/商户、行业人士、管理者；不同角色不能混成一个总体。
- 以过去的具体行为和最近一次经历为主，避免“你会不会”“你喜不喜欢我们的方案”等诱导题。
- 访谈结构：知情说明 → 热身 → 最近一次行为 → 困难与替代 → 机制追问 → 方案反应（可选）→ 反证与收尾。
- 主持人与记录员分工；取得录音许可后再录制。

### 追问规则

优先追问“请讲最近一次”“当时发生了什么”“你如何决定”“还有谁参与”“能给具体例子吗”。不推销、不争辩、不用评委式盘问。出现与假设相反的回答时继续追问，并纳入反证。

### 样本与饱和

定性访谈按关键人群分层。以是否持续出现新主题判断信息饱和，而不是把 5–8 人写成统计代表性。样本很少时输出机制线索和假设，不输出人群比例。

使用 [interview-guide-template.md](../assets/interview-guide-template.md)。

## 5. 问卷

### 设计顺序

1. 明确目标总体、抽样框和使用场景；
2. 将每个构念映射到题项与分析用途；
3. 先写筛选题和行为题，再写评价题与少量开放题；
4. 统一量表方向和标签，设计跳题；
5. 预测试认知理解、完成时长、逻辑和无效答案识别；
6. 预先确定排除、分群和分析规则。

### 禁止题型

- 双重问题：“价格和服务是否满意”；
- 暗示答案：“您是否同意本企业优秀的服务……”；
- 无时间范围：“经常”“平时”；
- 无可选边界的收入、消费或频率；
- 把未来意愿当真实行为；
- 为了得到想要结论而删除反向证据。

### 样本解释

概率抽样可按置信水平和误差范围估计样本；比例最保守时取 `p=0.5`：

```text
n0 = z² × p × (1-p) / e²
有限总体修正：n = n0 / (1 + (n0-1)/N)
```

校园、朋友圈、现场拦截和网络转发通常属于便利/配额样本。即使数量很大，也不得声称随机代表全市或全省；报告样本结构并只做相应范围的描述和比较。

本技能不设置通用的“最低有效问卷数”或“最低访谈数”。任何人数、份数和观察场次都必须标成研究团队的执行目标，而非官方门槛；应根据目标总体、分层、方法用途、时间资源、定性饱和和可接受误差说明理由。数量达标不等于证据充分，数量不足也不能靠伪造或降低清洗标准补齐。

使用 [survey-questionnaire-template.md](../assets/survey-questionnaire-template.md)。

## 6. 门店/网点观察

先获得必要许可，避免妨碍经营。使用统一表格跨场地、跨时段记录：

- 场地与商圈、时间、天气/活动等背景；
- 顾客旅程、动线、触点、排队、服务与异常；
- 商品/菜单/服务、价格、促销、缺货与陈列；
- 数字触点、到家/配送、售后与会员；
- 运营代理指标及其计算口径；
- 观察事实与研究者解释分栏记录。

至少包含案例企业和可比竞品；尽量覆盖工作日/周末、普通/高峰时段。不能录像时用时间戳笔记；不拍顾客面部、员工工牌、后台系统或商业秘密。

使用 [store-observation-template.md](../assets/store-observation-template.md)。

## 7. 竞品对标

先定义决策，再选对手：案例企业、3–5 个本地直接竞品、1–2 个间接替代或标杆。禁止只选全国知名企业而忽略当地真正争夺同一顾客/货流的对象。

### 行业维度

- **零售**：选址/覆盖、客群、品类、价格、促销、自有品牌、会员、服务、坪效代理、库存与即时零售。
- **餐饮**：商圈、客单、菜单、出餐、翻台代理、服务、外卖、供应链、加盟/直营和口碑。
- **物流**：网络覆盖、时效、价格、破损/投诉、揽派体验、仓配、客户结构、数字化和资源协同。
- **批发**：客户结构、采购、库存、账期、渠道、价格、仓储、配送、信息化和供应商关系。

每个评分维度先定义 1/3/5 分锚点，再评分；保存网页、照片、价格记录、观察或访谈等证据。没有数据时留空，不用主观印象补分。

使用 [competitive-benchmark-template.md](../assets/competitive-benchmark-template.md)。

## 8. 数据质量、伦理与证据综合

### 质量门

- 原始数据只读备份，清洗在副本进行；
- 每条记录有匿名 ID、来源、时间、地区和版本；
- 记录去重、缺失、异常和排除原因；
- 问卷量表、访谈编码和观察字段使用统一代码本；
- 访谈/评论主题保留支持证据和反证，不只计频次；
- 财务数据统一单位、期间和集团/地区口径。

### 洞察置信度

| 等级 | 条件 |
|---|---|
| 高 | 至少三类独立来源或多段样本一致，且存在行为/经营证据 |
| 中 | 两类来源相互支持，但局限于一个地区、渠道或人群 |
| 低 | 单一来源、被提问诱导、过旧、样本偏差大或只有态度 |

置信度不替代判断。重大结论若有强反证，必须并列呈现并解释边界。

### 无法进入企业内部时的降级规则

- 可以用公开经营披露、本地多时段观察、顾客/商户/供应商/前员工访谈和同口径竞品证据验证外显现象；
- 不得据此断言企业内部动机、成本结构、组织冲突、库存系统或管理者决策；
- 不能直接验证的内部根因降级为“待企业核实的机制假设”，方案改为带基线、试点、停止条件和回滚的验证设计；
- 若报告核心结论依赖该内部根因，调研门保持“待核实”；若能将问题重述为已被外部证据支持的经营现象并明确边界，可由指导教师和团队复核后进入报告。

### 伦理与隐私

告知目的、时长、活动、录音、用途、保存方式和退出权。只收集研究必需信息，匿名化后进入报告。涉及未成年人、健康、收入、身份或内部经营信息时提高审查门槛；不确定时不收集。

## 9. 阶段交付包

调研结束前必须交付：

1. 研究计划与变更记录；
2. 方法、样本与局限说明；
3. 研究材料最终版；
4. 原始数据清单、匿名化数据、清洗/排除日志；
5. 证据台账与竞品矩阵；
6. 主题/指标结果及反证；
7. “可写结论 / 暂不下结论 / 需补证”表；
8. 与报告章节和 60 分评分的映射。

缺少以上任一关键项时，不得将调研阶段标记为通过。
