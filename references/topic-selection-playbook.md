# 选题阶段操作手册

本手册用于把“按省份推荐企业”转化为符合 2026 细则、可调研、可分析、可答辩的案例选题。必须区分“官方对象规则与处罚”“官方评分要求”“本技能设置的选题门”和“辅导排序指标”，不得互相冒充。

## 一、官方条款与选题门边界

### 1. 案例对象必须合格

- 参赛队自行选择真实企业开展经营案例分析。
- 企业应属于流通行业。细则明确列举批发业、零售业、餐饮业、物流业；“等”允许其他流通业态，但边界案例必须说明其商品、服务或供应链流通属性。
- 所选企业应“较为典型、为大家所熟悉”。细则没有给出量化阈值，不得虚构官方门槛。
- 作品是对现实企业经营问题的案例分析，不是为虚构企业编制融资商业计划书，也不能只写品牌宣传或行业综述。

### 2. 官方评分要求：体现学校所在省的实际经营

- 研究对象必须能分析其在参赛队伍所在地区的实际发展状况，并体现地区性特点。
- 可选择外省企业，但该企业必须在院校所在省有可验证的布局与经营活动。
- 上述内容位于官方“分析对象”10 分评分项。细则没有把“本省无布局”单列为取消资格条款；本技能为避免先天丢失地区性分值，把“本省实际布局”提升为选题阶段门。这是备赛策略门，不得写成组委会资格处罚。
- “全国知名”“能网购”“用户听说过”不能单独证明本省实际布局。
- 可接受的布局证据包括：当地门店、仓储或分拨中心、直营网点、加盟网络、直营网约服务、区域公司、供应链基地、配送线路、区域业务公告或其他持续经营活动。
- 若只能证明一次性活动、广告投放或零散发货，标记 `[地区布局待核实]`，不得通过选题门。

### 3. 官方处罚规则：查重是“同校 + 同案例企业”，不是全国禁选

- 官方规则是：同一院校在 2025–2026 两年内，同一案例企业只能使用一次。
- 因而，某企业出现在其他院校的查重名单或获奖名单中，不构成本校自动禁选；它只提示选题拥挤、观点同质化或答辩比较压力。
- 查重对象是“案例企业”，不能只改作品题目规避。企业全称、品牌名、旧称、常用简称均需核对。
- 集团、子公司、品牌与加盟主体是否属于“同一案例企业”，细则未细化。存在控制关系、品牌共用或研究对象高度重合时一律标记 `REVIEW`，交由本校赛事负责人和组委会确认。
- 内置名单只能用于初筛。最终提交前必须核对竞赛官网最新名单和本校校赛登记记录。

### 4. 原创与 AI 边界

- 严禁抄袭，严禁完全使用 AI 撰写。
- 选题建议只能作为团队决策底稿；团队必须自行核实企业、完成一手调研、保留原始材料并实质性改写。

## 二、选题必需输入

优先收集以下信息：

1. 学校官方全称；
2. 学校所在省份；这里的“省份”以参赛院校所在地为准，不是队员籍贯、居住地或企业总部所在地；
3. 可开展实地调研的城市或区县；
4. 偏好的行业：批发、零售、餐饮、物流或其他流通业态；
5. 团队可接触的企业、门店、员工、供应商或消费者资源；
6. 可投入的调研时间、差旅半径和预算；
7. 已有候选企业、企业全称和品牌别名；
8. 研究生组、本科组或高职组，以及团队专业优势。

若用户只输入省份，先给省级“暂定候选池”，同时明确：缺少学校全称无法完成同校查重，缺少城市无法判断实地调研可达性，最终推荐状态只能是 `PROVISIONAL`。

## 三、按省份建立候选企业池

### 1. 分三层搜集 8–12 家企业

- **A 层：本省总部或本地代表性企业。** 优先考虑区域商超、连锁餐饮、批发市场、物流网络、本地生活服务等，通常地区性最自然。
- **B 层：外省总部、在本省有显著布局的企业。** 必须找到本省门店、仓配、区域公司或服务网络证据。
- **C 层：县域或细分业态典型企业。** 知名度可能较低，但能代表县域商业、社区零售、冷链、农产品流通、即时零售等区域问题；须补强“典型性和熟悉度”证据。

候选池至少覆盖两个流通业态，避免 8–12 家全部集中在同一种网红餐饮或全国连锁品牌。用户提供可调研城市后，长名单至少保留 4 家在该城市或团队可接受差旅半径内存在可观察门店、网点、市场、仓配或其他业务节点的企业；不足 4 家时明确扩展半径，不得虚高“一手调研可达性”。

### 2. 使用时效性来源核实

推荐具体企业时必须检索当前资料，优先级如下：

1. 企业官网、年度报告、招股书、社会责任报告、官方门店或网点查询；
2. 政府、商务部门、统计部门、市场监管、交通运输或邮政管理部门资料；
3. 交易所公告、行业协会和可信商业数据库；
4. 主流媒体的实地报道；
5. 地图、点评和社交平台仅作布局或消费现象线索，须交叉验证。

每个“本省有布局”“行业领先”“门店数量”“经营困难”等主张都要记录来源、发布日期、适用地区和核验日期。找不到证据时写 `[待核实]`，不把推测写成事实。

## 四、先硬筛，再评分

### 1. 硬性门禁

以下任一项不通过，不进入推荐前三。表中同时含官方对象/处罚要求和本技能的备赛策略门，已分别标注：

| 门禁 | 通过标准 | 不通过处理 |
|---|---|---|
| 行业归属 | 属于批发、零售、餐饮、物流等流通行业 | 淘汰或补充行业边界说明 |
| 真实企业 | 企业和经营活动可由可靠来源验证 | 淘汰 |
| 地区布局（技能策略门） | 在学校所在省存在可验证的实际经营 | 淘汰或标记待核实，不得定案；不要称为官方资格处罚 |
| 同校查重（官方处罚风险） | 校方核对后达到 `CONFIRMED_CLEAR` | `BLOCK` 淘汰；`REVIEW`、`CLEAR_IN_FILE` 或 `PROVISIONAL` 暂缓 |
| 研究伦理 | 可在合法、知情、不过度收集个人信息的前提下研究 | 淘汰或改换研究方法 |
| 原创空间 | 不是复制往届作品，团队能够形成自己的地区证据链 | 淘汰或重构问题 |

### 2. 竞争力评分（辅导工具，非官方分值）

仅对通过选题门的企业按 100 分排序：

| 维度 | 分值 | 判断标准 |
|---|---:|---|
| 地区问题强度 | 20 | 本省布局真实，能形成与全国、其他城市或企业内部网点的比较 |
| 一手调研可达性 | 20 | 团队能观察门店/网点，接触顾客、员工、供应商或合作方 |
| 公开数据可得性 | 15 | 有年报、经营数据、政策、行业和竞品资料，可交叉验证 |
| 典型性与熟悉度 | 15 | 有代表性、公众认知或行业地位的可靠证据 |
| 经营矛盾可诊断性 | 15 | 问题可量化，存在机制和决策空间，不只是泛泛“提升品牌” |
| 新颖性与差异化 | 10 | 能形成地区特有视角，避开往届高频套路或提出新机制 |
| 交付可控性 | 5 | 时间、预算、样本、技能与数据处理难度适配团队 |
| **合计** | **100** | 80 分以上优先；70–79 分备选；低于 70 分一般不推荐 |

评分必须附来源 ID、证据置信度和判断依据。没有证据的维度不得给满分；关键事实尚未核实时给分数区间或写“暂不评分”，不得用精确总分制造确定性。

## 五、查重执行流程

### 1. 收集企业身份

至少记录：

- 企业工商或官方全称；
- 品牌名、简称、旧称；
- 母公司、核心子公司和加盟经营主体；
- 拟研究的具体地区业务单元。

### 2. 使用内置工具初筛

```bash
python3 scripts/check_case_duplicate.py \
  --school "学校官方全称" \
  --enterprise "企业全称|品牌名|常用简称" \
  --title "拟定作品标题"
```

解释结果：

- `BLOCK`：同校名单中出现强企业命中。停止该企业的拟题与写作，转向备选。
- `REVIEW`：出现别名、模糊命中、相似标题或企业主体关系风险。由本校赛事负责人核对原作品与最新名单。
- `CLEAR_IN_FILE`：仅代表内置 2025 名单没有发现同校命中，不等于组委会最终认定。
- `CONFIRMED_CLEAR`：本校赛事负责人已核对官网最新名单、本校 2025–2026 登记记录和案例企业身份后确认可用。此状态只能人工记录，脚本不能自动给出。

其他院校的同企业获奖题目只用于识别已有视角与避免同质化，不应输出为 `BLOCK`。
创意作品名可能完全不写企业名称，因此还要阅读工具输出的全部同校作品标题，并向本校负责人核对这些作品对应的案例企业；不能仅凭字符串未命中就定案。

### 3. 最终人工确认

在选题定案和提交前各确认一次：

1. 官网最新查重名单是否更新；
2. 本校 2025、2026 校赛已登记但未必获奖的作品；
3. 企业别名、子公司、品牌与集团关系；
4. 本校负责教师或组委会的书面确认。

## 六、从企业生成“能研究的题目”

### 1. 先找矛盾，不先造标题

对每个候选企业提出 3–5 个待验证问题：

- 全国模式与本省消费、渠道、地理或政策之间有什么不匹配？
- 企业在本省的增长、效率、体验、库存、履约、组织或盈利指标有什么可观察差距？
- 差距可能由哪些机制引起？哪些证据能证伪？
- 企业有哪些真实可执行的决策选项？

未经调研只能写“候选矛盾”或“待验证假设”，不得提前断言企业存在某项失败或财务危机。

### 2. 中心命题公式

> 在【省/市与经营阶段】，案例企业面临【可量化或可观察的地区经营矛盾】；团队将用【公开资料 + 一手方法】验证【机制】，并提出【行动组合】改善【核心指标】。

### 3. 标题公式

每家进入前三的企业给 2–3 个标题方向：

1. **诊断型**：`【地区情境】下【企业】的【经营矛盾】诊断与优化研究`
2. **机制型**：`从【关键机制】看【企业】在【地区】的【经营问题】——基于【证据/方法】的案例分析`
3. **行动型**：`【目标】如何实现：【企业】【地区业务】的【策略组合】与实施路径`

标题应包含企业、地区和经营问题；可以有表达力，但不能用口号替代研究对象。避免在题目中预先写入尚未验证的因果结论。

## 七、推荐结果的固定输出

选题阶段必须按以下顺序交付：

1. **输入与限制**：学校、所在省、可调研城市、偏好、资源和缺失信息；
2. **官方规则摘要**：行业、典型性、地区布局、同校查重和原创边界；
3. **候选长名单**：8–12 家，标出 A/B/C 层、行业、地区布局证据、典型性证据和选题门状态；
4. **评分表**：仅给通过选题门的企业评分，显示依据而非只报总分；
5. **前三名**：每家写推荐理由、主要风险、可调研对象、候选矛盾和 2–3 个题目；
6. **唯一首选**：说明为何它比第二名更适合该团队，以及需要在 72 小时内验证的关键假设；
7. **查重结论**：逐家给 `BLOCK / REVIEW / CLEAR_IN_FILE / CONFIRMED_CLEAR / PROVISIONAL`，列出命中记录、人工确认人和日期；
8. **选题决定卡**：企业、地区、中心命题、证据计划、淘汰条件和阶段门结论。

不得只列知名企业名称，也不得在没有学校全称时宣称“该企业不在查重名单内”。

## 八、选题阶段门

仅当下列条件全部满足，才进入调研：

- 企业及业态真实，流通属性明确；
- 典型性与公众熟悉度有至少两类可靠证据；
- 学校所在省的实际布局已核实；
- 同校企业查重已由本校赛事负责人核对并记录为 `CONFIRMED_CLEAR`；
- 至少有一条可观察、可量化、可证伪的地区经营矛盾；
- 能覆盖战略、商业模式、运营、市场竞争、财务五个经营维度；
- 至少存在两类一手调研入口和两类公开资料来源；
- 团队确认最终选题，并记录淘汰备选的理由。

若任一项缺失，状态为 `待核实`；遇到行业不符、地区无布局或同校强命中，状态为 `阻断`。
