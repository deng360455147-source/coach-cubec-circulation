# Excalidraw、thesis-figure-skill 与 imagegen 正文配图协议

本协议用于第3—10章的研究框架、价值链、经营机制、流程、根因、方案和路线图。每一批正文配图都必须读取并调用外部 `$excalidraw-diagram`、`$thesis-figure-skill` 和系统 `$imagegen`，同时在内部图表地图记录路由结果。Excalidraw默认承担结构图，thesis-figure-skill承担学术构图复核以及适配的公式/TikZ/高密度机制图重绘，imagegen只辅助适配的无文字位图素材。统计图、财务图、市场份额图、热力图和模型诊断图仍由已验证数据与可复现程序生成。任何工具名、文件路径、提示词或生产状态均不得进入参赛正文。

## 1. 工具边界

| 视觉任务 | 默认工具 | 不得替代的证据 |
|---|---|---|
| 研究框架、流程、机制、价值链、三流协同、根因链、泳道、路线图 | `$excalidraw-diagram` | 年报数字、问卷样本、访谈原话、统计检验 |
| 学术构图审查、公式/TikZ、高密度机制关系或Excalidraw难以稳定表达的图形 | `$thesis-figure-skill` | 数据计算、因果识别、事实关系与来源核验 |
| 折线、柱状、组合、热力、词频、地图、模型结果/诊断 | 数据验证 + 可复现可视化程序 | 原始数据、口径、代码与诊断 |
| 经授权的场景示意、无文字氛围图、产品/服务概念插画 | `$imagegen` 辅助 | 现场照片、企业真实门店、真实产品、经营结果 |
| 年报原图、现场照片、竞品页面或产品证据 | 原件裁切与合法标注 | 不得生成、换物、补人或改写事实细节 |

`$imagegen` 不用于简单形状、精确流程、带大量中文标签的结构图，也不生成企业事实、数据图、地图、Logo或仿真的调研证据。若位图需要准确文字，先生成无字底图，再在Excalidraw或Word中加入经核验的文字；普通标签在最终Word宽度下不得小于14pt，关键标签和关键数字为16pt。

## 2. 每批三工具调用门

开始制作配图前，逐项完整读取三个Skill的当前 `SKILL.md`，再在 `report_visual_system.drawing_skill_invocations` 中记录：

- `excalidraw-diagram` 必须为 `INVOKED_USED`，并保存可编辑源文件和导出文件；
- `thesis-figure-skill` 必须为 `INVOKED_REVIEWED` 或 `INVOKED_USED`，前者记录学术构图审查，后者同时记录实际重绘输出；
- `imagegen` 必须完成适配性判断。适合实际位图时记录 `INVOKED_USED`；不适合时记录 `INVOKED_NOT_APPLICABLE` 和原因，不得为了调用而生成装饰图。

任何实际绘制都要遵循相应Skill的用户选择、依赖、审查和输出要求。三个工具的调用记录只存在于内部图表地图，不得复制到参赛正文。

## 3. 每张图的前置契约

制作前记录：章节、唯一判断、证据与来源、目标宽度、图形家族、节点/关系、可证伪边界、是否含文字、源文件与导出文件。图片插入Word之前必须有一段完整正文，先说明“为什么要看这张图、图中比较什么、读者应关注什么”，不能让标题或一级/二级/三级标题直接连接图片。

图片正文引导句必须承接相邻论证，不写“如下图所示”作为唯一内容。图后使用Word外置题注与来源注，不能把“图4-1 ×××”或任何题注复制进画布或图片像素。

## 4. 报告专用 Excalidraw 规则

生成前完整读取 `$excalidraw-diagram` 的 `SKILL.md`、色板和相关元素模板，并执行其“概念—视觉结构—渲染—查看—修复”闭环。本报告在上游通用规则上增加以下强制覆盖：

1. 结构必须表达因果、顺序、汇聚、分流、层级或约束，不能把段落做成等宽卡片阵列。
2. 主色使用墨蓝，辅助色使用低饱和金/蓝灰，页面保持白底；概念图可用轻度手绘边线，精确流程和度量关系使用清晰直线。
3. 图内不放总标题、图号、题注、来源全文或工具名；Word外部负责题注和来源。
4. 所有实际出现在图内的中文、英文和数字，按最终Word嵌入尺寸折算后不得小于14pt；这一门槛覆盖节点、轴线、刻度、图例、数据标签和注释，关键节点、主标签和关键数字为16pt。若Word按原导出宽度的75%嵌入，普通标签的源字号至少约为25px，不能继续沿用16px。统一使用 `有效字号(pt) = 源字号(px) × 72/96 × 最终宽度/导出宽度` 复算，不能只看源画布字号。
5. 字号只使用14pt普通标签与16pt关键标签两档。结构层级主要通过位置、留白、颜色、线宽和形状表达；信息放不下时拆成总图与分图，或把解释移到正文，不得缩字。
6. 保存可编辑 `.excalidraw`、高分辨率PNG或SVG导出和渲染预览；至少完成两轮“渲染—查看—修复”，检查截字、重叠、歧义连线、过密、留白失衡和100%视图可读性。

报告色板见 [excalidraw-report-palette.md](../assets/excalidraw-report-palette.md)。该色板是本项目覆盖，不修改或再分发上游仓库内容。

## 5. thesis-figure-skill 学术构图复核

每批至少使用 `$thesis-figure-skill` 对研究框架、关键机制图或瓶颈—方案图进行一次学术构图复核。审查重点包括主视觉中心、阅读路径、关系语义、标签密度、公式可读性、数据与箭头是否越过证据边界，以及正常打印尺寸下的文字可读性。若Excalidraw无法稳定表达公式、复杂层级或高密度机制关系，再按该Skill的用户选择和生产流程实际重绘；普通图不应为了使用TikZ而增加复杂度。

## 6. imagegen 辅助规则

只有位图比结构图、数据图或原始证据更合适时才调用 `$imagegen`。提示词必须写明：无标题、无题注、无Logo、无水印、无数值、无不可验证企业事实、保留足够空白供后续排版。生成后保存提示词、输出路径、用途、是否含文字、人工核验结果和许可/使用边界。

生成图不得冒充企业实拍、消费者调研、访谈对象或方案实施效果。若生成内容可能被理解为事实，应在合法且不影响参赛匿名的正常来源注中标为“示意图”，并确保正文不据此得出经营结论。带文字的位图一律退回：删除文字后重生成，准确标签由Excalidraw或Word以不小于14pt添加，关键标签使用16pt。

## 7. Word落版规则

- 图前：紧邻一段正文引导文字；
- 图片：内联、保持比例、不得内嵌题注，图内普通文字最终有效字号不小于14pt，关键文字为16pt；
- 图后：小五9pt黑体居中的Word `SEQ 图`题注；
- 来源：题注后使用9pt宋体，注明机构/文件、期间、页码/表号、访问日期或团队制作依据；
- 表格：表题在上，所有单元格水平与垂直居中，单元格段落显式取消首行缩进；
- 分页：图片与题注尽量同页，但不得通过手工分页符处理；只用一级标题“段前分页”形成章节分页。

## 8. 验收

自动校验负责检查三工具调用记录、图片前置正文、外置自动题注、表格单元格居中与零首行缩进、1.25倍行距、三级目录和分页规则。图内无题注、普通文字有效字号不小于14pt、关键文字16pt、Excalidraw构图质量、thesis-figure学术构图复核、imagegen事实边界和最终打印清晰度必须通过逐页人工检查，并在Word视觉清单中逐图声明。
