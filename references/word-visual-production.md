# Word版式、学术图解与逐页视觉门禁

本协议用于制作B01、B02、B03三批审阅DOCX及最终合并DOCX/PDF。内容真实性优先于美化；图片和表格必须承担分析任务，不得装饰性填页。所有参赛正文使用正常经营分析语言，不出现工具名、代码路径、状态码或内部证据ID。

## 1. 能力路由

- **数据验证**：先调用 `$data-analytics:validate-data`，检查来源、样本、分母、期间、单位、计算、比较和因果措辞。
- **统计图表**：调用 `$data-analytics:visualize-data`，以真实数据文件生成可复现SVG或高分辨率PNG；折线、柱状、组合、热力、词云等必须分别通过数据门。
- **机制/流程图解**：读取 [thesis-figure-integration.md](thesis-figure-integration.md) 和 `integrations/thesis-figure-skill/SKILL.md`，用于研究框架、价值链、流程、驱动树、泳道、路线图和瓶颈—方案机制。不得用它替代统计验证。
- **Word生成与检查**：调用 `$documents:documents`，使用Word真实样式、表格几何、内联图片、页眉页脚、`SEQ/REF`域、隐私清理和逐页渲染流程。
- **编辑式视觉参考**：Kami 1.12.0原样嵌入 `integrations/kami/`，只借鉴克制层级、图解语言和页面密度。其原生输出是HTML/PDF，不得冒充Word生成器。

Word只能从 `report-reader-b01/b02/b03-template.md` 或最终读者合并稿生成。含状态、证据ID和程序路径的 `report-section-batch-template.md` 永不转换为用户Word。

## 2. 固定版式预设

默认读取 [report-word-format-profile.json](../assets/report-word-format-profile.json)，将其中每个数值显式写入DOCX样式和节属性。当届细则、学校正式模板或用户后续明确要求优先；任何偏离须记录为命名覆盖，不能靠Word默认值或逐段手工格式化。

### 2.1 页面与正文

| 项目 | 默认值 |
|---|---|
| 页面 | A4竖版；上/下2.54cm，左/右3.17cm |
| 中文正文 | 小四宋体，12pt；内容特别密集时可用五号10.5pt，但必须打印清晰并经用户允许 |
| 英文与数字 | Times New Roman，与所在中文同号 |
| 段落 | 两端对齐，首行缩进2字符，默认1.5倍行距；必要时统一采用固定26—29磅 |
| 一级标题 | 四号黑体加粗，14pt，段前/段后各0.5行 |
| 二级标题 | 小四宋体加粗，12pt；与正文同号，靠加粗区分 |
| 三级标题 | 小四宋体加粗，12pt；使用真实Heading 3样式 |
| 正文强调 | 只用加粗或下划线，不能靠彩色大字和高亮堆叠 |

标题使用Word真实Heading 1/2/3样式和多级编号，目录从标题样式自动生成；不得键入假标题或手工页码。中文字体缺失时选择可复现回退，并在全部渲染页中复核，不可静默换字体。

### 2.2 页眉页脚与匿名

- 封面启用“首页不同”，不显示普通页眉；仅保留官方允许的团队名称、作品名称和案例企业名称，不出现学校、成员、联系方式或校徽。
- 正文页眉保持单行、低对比度；可使用匿名短题名和当前一级章节名，不放批次、版本、工具或内部标签。
- 盲审版本默认隐藏页码；非盲审或用户要求时，使用页脚真实 `PAGE/NUMPAGES` 域，不手工输入。
- 交付前清理 creator、lastModifiedBy、自定义属性、修订、批注、隐藏文本、图片元数据和可识别路径。

## 3. 图题、表题、来源与自动编号

1. **图题**：置于图下方，独立段落、居中、五号黑体10.5pt。
2. **表题**：置于表上方，独立段落、居中、五号黑体10.5pt。
3. **自动编号**：图、表分别使用真实Word `SEQ`域形成全文独立连续序列；正文引用使用书签与 `REF`域。禁止手工输入编号后冒充自动题注。
4. **无头渲染**：插入域后物化显示值，确保LibreOffice/PDF/PNG中编号可见；最终在Word中更新全部域后再次渲染，修改图表顺序后必须重新物化。
5. **来源注**：图题或表格后紧邻普通段落，默认9pt宋体/Times New Roman左对齐，写明机构/企业、文件或数据集、年度/发布日期、页码/表号、样本、单位、计算或访问日期。
6. **位置**：图片默认内联。图题必须紧邻其图，表题必须紧邻其表；不得跨页漂移。表格允许重复表头，但禁止固定行高截字。

所有图、表及正文交叉引用在合并全文后统一刷新。运行 `scripts/validate_report_docx_format.py` 检查A4、页边距、样式、题注位置和 `SEQ`域；仍须人工逐页确认。

## 4. 图表与图片生产

### 4.1 每张图表契约

记录章节、主张、分析问题、数据/事实来源、期间、地区、样本、分母、单位、清洗、适用图形、标题、重点读数、邻接解释、生成文件和最终图号。数据不足时改用表格、斜率图、流程图或文字，不模拟数据补图。

每张图只支持一个主要判断，正文完成“读数—比较—解释—经营含义—限制”。趋势图需要足够连续观察点；问卷图标注有效样本和抽样边界；财务图保留币种、合并范围和计算式；竞品比较保持同地区、同场景、同期、同口径。

### 4.2 字号与清晰度

- 普通图内标签在Word最终尺寸不得小于11pt，图例/必要注释不得小于10.5pt，关键数字宜为12pt以上。
- 优先SVG/PDF矢量图；位图按最终宽度至少220dpi，不放大模糊截图。
- 使用主报告统一字体和配色；整批可以轮换图形家族与版式，但不能每张图套一套互不相干的主题。
- 图形生成后在100%页面视图和200%检查视图各复核一次，并做黑白打印可辨性检查。
- 图片不得改动企业年报、现场照片或原始证据的事实含义；裁切、遮挡和隐私处理须有记录。

B02/B03按 [national-first-b02-b03-writing-visual-patterns.md](national-first-b02-b03-writing-visual-patterns.md) 填写图表地图：整批至少5个视觉家族、3种风格模式和3种页面版式，单一家族不超过40%；不得复制国一作品的边框、吉祥物、水印、封面或成品图。

## 5. 附录的专业呈现

### 5.1 问卷和访谈

- 问卷使用 [survey-questionnaire-template.md](../assets/survey-questionnaire-template.md)：包含知情说明、筛选/跳题、最近一次行为、构念量表、竞品/痛点、必要分层、开放题、预测试、清洗和变量编码。
- 访谈使用 [interview-guide-template.md](../assets/interview-guide-template.md)：按管理层、门店/网点负责人、一线员工、供应商/加盟商和消费者分角色，保留知情、录音/材料同意、反证、匿名编号、主题代码本和使用边界。
- 只展示团队真实执行版本和真实样本说明。尚未实施时明确为“拟用/预测试版本”，不填写虚构回收、匿名ID、原话、饱和度或统计结果。

### 5.2 参考文献

参考文献采用现行 `GB/T 7714—2025` 顺序编码制和期刊式文后列表：普通段落、连续编号、悬挂缩进2字符；中文宋体、英文与数字Times New Roman。网页写明发布机构、题名、发布日期、URL和访问日期；年报/公告保留企业、文件名、年份和页码；期刊文献保留作者、题名、刊名、年份、卷期页码和DOI（如有）。

**禁止把参考文献排成表格。** 11.4.1与11.4.2若按框架分组，编号仍全文连续，正文引文能反向定位。为满足页面视觉要求，参考文献页只能使用由真实引用台账计算的“来源类型/年份/章节引用覆盖图”，不得重复装饰图，更不得把文献条目塞进隐藏边框表格。

## 6. 逐页视觉门禁

“每页有图片或表格”以最终渲染页为准。每页至少含一张与本页判断相关、带题注和来源的图片，或一张真正用于比较/查阅的表格。第3—10章叙述性页面至少60%含分析性图片，且不能连续两页都只有文字或表格。

不计入覆盖：Logo、装饰照、重复水印、无来源网图、色块、文字截图、段落套表格。参考文献条目必须保持普通列表；参考文献页若需要视觉，只能使用真实引用台账生成的非装饰分析图。

## 7. 每批DOCX生产步骤

1. 锁定当前批次的证据和读者正文，运行 `validate_reader_facing_report.py`。
2. 读取版式JSON，建立Word样式、节、页眉页脚、真实多级编号和题注样式。
3. 验证数据，再制作统计图；对适配的机制/流程图调用学术图解链路。
4. 生成DOCX：图片内联、图题在下、表题在上、来源紧邻、替代文本完整。
5. 插入 `SEQ/REF`域并物化显示值；更新目录和页码域。
6. 运行正文泄漏、样式、图片、可访问性、隐私和 `scripts/validate_report_docx_format.py` 检查。
7. 渲染为逐页PNG及PDF；在100%逐页检查图表覆盖、字号、截字、重叠、分页、题注位置、来源、页眉页脚和匿名。
8. B02/B03运行图表地图生产校验；按真实页填写Word视觉清单并运行清单校验。
9. 任一修改都重新刷新域、重新渲染和重新检查；通过后交付当前批DOCX并等待用户确认。
10. 三批均确认后写概要和目录，合并全文并从第1步重新执行，不能沿用分批结果代替全文复核。

## 8. 发布检查

- DOCX、PDF、目录、图题、表题、文中引用和参考文献来自同一版本；
- 所有题注均为10.5pt黑体居中，图下表上，`SEQ`域自动编号；
- 正文为12pt宋体，英文数字Times New Roman；两端对齐、首行2字符、版式和页边距符合预设；
- 图内字在最终宽度清晰可读，矢量优先，未出现低清放大或标签重叠；
- 问卷、访谈和编码为真实执行版本，知情、样本、质量和局限透明；
- 参考文献为GB/T 7714—2025普通编号列表，不是表格；
- 每页图文门禁、匿名、元数据、来源合法性和内部语言清理通过；
- 自动脚本只证明结构与文件属性，不证明事实真实、问卷有效或因果成立。
