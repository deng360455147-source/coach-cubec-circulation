该 skill 生成固定 1920×1080、零构建依赖、单文件 HTML 演示，支持动画、键盘/触控导航、浏览器内文字编辑和可选 PDF 导出。它**不原生生成可编辑 PPTX**。

## 运行边界

1. 大纲阶段不调用 `$frontend-slides`，不安装浏览器依赖，不生成视觉成稿。
2. 只有 JSON 通过 `scripts/validate_ppt_outline.py --for-production` 且项目状态为 `PPT_OUTLINE_APPROVED` 后才调用 `$frontend-slides`。
3. 仓库的 `scripts/export-pdf.sh` 会安装未固定版本的 Playwright/Chromium，并启动未显式限制到回环地址的静态文件服务。本主 skill **不直接运行该脚本**；用户需要 PDF 时，调用已配置的 PDF 技能/受控浏览器渲染流程逐页生成并复核。
4. `scripts/deploy.sh` 可能安装 Vercel CLI、触发登录，并把演示或文件夹上传到公网。除非用户明确要求发布并确认上传范围，否则绝不运行。
5. 不把整份报告、调研原始数据、受访者信息或内部资料上传到外部服务。演示只使用匿名化、已确认可公开的内容。
6. 更新第三方版本前重新审计 `SKILL.md`、脚本、依赖、许可证和提交差异；不自动跟随 `main`。

## 制作合同

### 输入

- `PPT_OUTLINE_APPROVED` 的20页大纲；
- 锁定报告及来源定位；
- 用户提供并确认可使用的图片/Logo，或可核验的公开视觉来源；
- 匿名规则和禁用标识。

将外部 skill 的内容发现参数直接设为：

| 参数 | 固定值 |
|---|---|
| Purpose | 竞赛现场路演 / Pitch |
| Length | 20 slides |
| Content | All content ready |
| Density | Low density / speaker-led |

已由主 skill 确定的参数不要重复询问；只询问仍缺的受众、风格偏好或素材授权。

### 风格确认

按 `$frontend-slides` 规则生成 3 个真实封面预览：一个克制专业方案、一个与案例行业匹配的鲜明方案、一个有明确视觉命题的自定义方案。预览中只出现真实作品内容，不出现“方案 A”“模板名”“AI 生成”等工作流文字。

用户选定后记录风格名、字体、主辅色、图形语言和选择理由。国一样本不参与视觉选择，不能复制其配色、品牌装饰或页面。

### HTML 成稿

1. 恰好20个含 `slide` 类的页面元素；顺序与已确认大纲一致。
2. 每页固定 1920×1080，整体等比缩放；禁止移动端重排。
3. 每页一个主结论，低密度、讲者主导；正文不得缩到投屏不可读。
4. 在文件顶部加入 `<!-- SOURCE_REPORT: 报告标识/版本 -->`。
5. 页2–20的页面元素增加 `data-source="报告页/章节/图表或证据ID"`；多项用分号分隔。
6. 结论和数字与锁定报告一致；不为了视觉效果创造新 KPI、新调研结果或新方案收益。
7. 图片必须有身份和来源；不得生成伪截图、伪 Logo、伪门店照片或伪数据图。
8. 保留 `prefers-reduced-motion`，不使用影响阅读或计时的冗长动画。
9. 竞赛现场版本不得依赖实时网络字体或 CDN；将许可允许的字体和必要图片内嵌，或制作完整离线包，并在断网状态下完成一次全篇播放。

## QA 门

至少逐页检查：

- 数量恰好20，顺序和标题与大纲一致；
- 结论、数字、单位、地区、期间、样本量和来源定位一致；
- 无 `[待报告补证]`、占位文字、学校/姓名/联系方式/校徽；
- 1920×1080、1280×720 与一个手机视口下无裁切、溢出、重叠或多页同时显示；
- 字体、图片和图表加载完成；导航、页码、键盘、触控和减弱动画可用；
- 断开网络后仍能完整播放，字体替换不会造成换行、裁切或版式漂移；
- 逐页截图复核，至少完成一次完整20页播放。

## 输出格式

- 默认：单文件 HTML；
- 可选：调用 PDF 技能从确认后的 HTML 生成静态 PDF，动画不保留；
- 可编辑PPTX：先完成并确认HTML视觉稿，再调用演示文稿技能，以artifact-tool重建相同的20页结构、视觉系统和来源注释；不得声称是frontend-slides原生导出。
