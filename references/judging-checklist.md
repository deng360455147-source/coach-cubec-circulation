# 评分复核快速检查

正式评分先读 [scoring-review-protocol.md](scoring-review-protocol.md) 和 [scoring-rubric-60.md](scoring-rubric-60.md)。本表只用于最后检查，不能替代证据矩阵。

## A. 评分前

- [ ] 锁定唯一报告版本；记录文件类型、页数/字数、完整性和可读性。
- [ ] 标记 `SCORABLE / PROVISIONAL / UNSCORABLE`。
- [ ] 标记 `REPORT_ONLY / PARTIALLY_VERIFIED / EVIDENCE_VERIFIED`。
- [ ] 对话报告只包含已接受章节；上传报告已检查正文、图表、附录和参考资料。
- [ ] PDF/DOCX 使用对应技能读取；扫描页和关键图表已视觉检查。

## B. 资格、匿名与格式（不计入60分）

逐项写 `PASS / NOT_VERIFIED / RISK / BLOCK`、规则性质和定位：

- [ ] 企业属于流通行业并具有典型性。
- [ ] 外省企业在院校所在省有实际布局；这是“分析对象”评分要求，本技能将其作为保守选题门，不冒充官方资格取消条款。
- [ ] 同校 2025–2026 未重复案例企业；已由官方/校方确认。
- [ ] 报告并非完全由 AI 撰写，团队原创贡献与底稿可追溯。
- [ ] 封面、正文、图表、附件及属性无院校、姓名、联系方式泄露。
- [ ] A4 竖版 PDF、不少于 3000 字；目录和参考资料完整。

未提供参赛身份、知识赛、查重或原创材料时标 `NOT_VERIFIED`，不得猜测通过。匿名泄露按细则属于扣分风险；同校企业重复、抄袭或完全使用 AI 撰写才可能触发取消资格，不得把所有问题统称“一票否决”。

## C. 60分证据矩阵

每项先记录 `R/V/I/M`、精确定位、反证和上限，再评分：

| 官方维度 | 满分 | 必查任务 |
|---|---:|---|
| 分析框架 | 20 | 中心命题、因果闭环、层次取舍、证据对标、图表与跨章一致 |
| 分析对象 | 10 | 战略/模式/运营/市场/财务实质覆盖；目标地区实际发展与机制 |
| 分析视角 | 10 | 是否改变问题/决策；是否企业—地区—阶段特异；边界是否清楚 |
| 分析方法 | 10 | 问题适配、真实执行、结果解释、样本/清洗/交叉验证和局限 |
| 分析结论 | 10 | 回答问题、根因映射、责任资源、KPI试点、风险回滚和现实意义 |

- [ ] 第一遍逐维度取证评分完成，未先看总分。
- [ ] 第二遍反向审计完成，检查口径、因果、方法空转和方案泛化。
- [ ] 分歧超阈值的维度已设 `LOW`，没有简单平均。
- [ ] 总分、区间、上限、证据字段已通过校验脚本。

## D. 国一成熟度诊断（不加分）

- [ ] 地区性成为因果变量。
- [ ] 一个经营矛盾统领全文。
- [ ] 成功机制与阶段瓶颈双线呈现。
- [ ] 方法和数据服务问题。
- [ ] 瓶颈与方案镜像对应。
- [ ] 图表承担判断。
- [ ] 附录支持复核。

每项写 `成熟 / 部分 / 缺失 / 无法判断`、报告定位和影响的官方维度，不生成额外总分。

## E. 最终交付

- [ ] 工作分与合理区间均标“辅导估计”。
- [ ] 置信度符合来源核验状态和双遍分歧。
- [ ] 报告事实与外部核验事实已区分。
- [ ] 使用“未定位/未核验”，没有把未知写成不存在或已证实。
- [ ] 修改项按影响高/中/低排序，没有承诺固定涨分或奖项。
- [ ] 团队必须补证、核验和实质性重写的事项已列出。
