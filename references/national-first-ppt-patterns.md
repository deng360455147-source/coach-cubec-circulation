## 样本边界

| 样本 | 页数 | 主要叙事顺序 |
|---|---:|---|
| 数字转型下区域零售的突围路径——基于芜湖三只松鼠的流通业实践研究 | 31 | 研究要核 → 企业/芜湖画像 → 内外部研判 → 运营模式与三类瓶颈 → 产品/渠道/物流/政策方案 → 理论与行业价值 |

## 逐份结构观察

### 三只松鼠样本

- 页 1–7：封面、目录、背景/区域价值、目标、方法、核心发现；
- 页 8–12：企业发展、政企合作、本地化实践、数字化成果；
- 页 13–18：内部资源/能力、宏观环境、竞争与区域机会；
- 页 19–24：全渠道和供应链模式、产品同质化、物流成本、品牌老化；
- 页 25–30：产品、渠道、物流、政策方案及行业价值；
- 页 31：结束页。

特点是“研究设计与核心发现前置”“本地经营证据密集”“瓶颈与方案镜像”。风险是大量数字缺少可复核的页内来源口径，不能直接继承。

### 蜜雪冰城样本

- 页 1–6：封面、目录、品牌历程、定位、形象与品质；
- 页 7–9：市场竞争与消费者需求；
- 页 10–13：组织、员工、标准化管理及运营成效；
- 页 14–19：经济、社会文化、技术和政策环境；
- 页 20–24：产品、价格、渠道、促销等营销组合；
- 页 25–28：消费、数字化、健康、成本和创新等未来议题；
- 页 29：结束页。

特点是品牌化视觉统一、章节识别强、河南语境贯穿。风险是目录式标题、装饰性过强和分析链较松，不能把“好看”误当作证据充分。

### 瑞幸样本

- 页 1–4：封面、目录、核心结论先行、方法论；
- 页 5–7：山东规模、城市梯队与消费者；
- 页 8–11：竞争、供应链、品牌信任三类挑战；
- 页 12–16：数字化、供应链、会员、组织与财务根基；
- 页 17–21：政策经济、全国连锁、本土品牌和顾客需求；
- 页 22–26：门店、数字化、供应链运营模式；
- 页 27–34：产品、供应链、渠道、品牌方案与结论；
- 页 35：结束页。

特点是“核心判断先行”“挑战前置后再解释”“区域化行动包完整”。风险包括文字密度高、个别页保留模板占位文字、部分推断与事实未清楚区分。

## 三份样本的共同功能

| 功能 | 出现情况 | 可蒸馏原则 |
|---|---:|---|
| 匿名封面与清晰题目 | 3/3 | 标题直接给出地区、企业和经营议题 |
| 导航/章节识别 | 3/3 | 可改为页眉进度，不必浪费完整目录页 |
| 企业与目标地区画像 | 3/3 | 全国事实必须落到本地经营节点 |
| 内部经营分析 | 3/3 | 战略、模式、运营、市场、财务不能缺位 |
| 外部环境和竞争 | 3/3 | 只保留会改变经营决策的变量 |
| 经营模式/营销模式拆解 | 3/3 | 从流程和机制解释结果，不堆框架名称 |
| 成功经验与问题并陈 | 3/3 | 先说明为什么有效，再说明边界与瓶颈 |
| 核心瓶颈 | 3/3 | 症状、差距、根因、影响必须分开 |
| 对应方案 | 3/3 | 产品/供应链/渠道/品牌等行动直接对应根因 |
| 结论或行业价值 | 3/3 | 回答研究问题并说明复制边界 |
| 研究方法与限制 | 2/3 明确 | 新版必须补齐，防止数字和因果失去来源 |

## 蒸馏结论

最稳定的路演主线是：

```text
核心判断
  → 为什么研究该地区与企业
  → 数据与方法边界
  → 企业/市场/经营五维证据
  → 已有成功机制
  → 核心瓶颈与根因
  → 镜像行动包
  → 实施、指标、风险与行业价值
```

将29–35页样本压缩为20页时，优先删除完整目录页、重复章节页、企业百科、框架释义和纯结束页，并合并同一因果链中的成功机制、瓶颈与根因页；不能删除方法与限制、财务口径、根因证据、方案实施和风险回滚。

## 明确不继承

- 不复制样本的文字、数字、图片、图表、配色、版式、水印、吉祥物或品牌素材；
- 不把样本未标来源的数据当作可用事实；
- 不保留“单击此处”“工作计划/年终汇报”等模板残留；
- 不用大段文字、纯章节分隔和纯“谢谢”页挤占 10 分钟；
- 不因样本使用 SWOT/PESTEL/4P 就强制所有项目照搬方法。
