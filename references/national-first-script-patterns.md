# 国一路演稿样本的结构观察

## 样本边界

本文件分析用户提供的两份 DOCX。用户将其作为国一样本，本技能未独立核验获奖等级；样本中的企业事实、数字、来源和因果均未重新核实，只能观察路演结构与语言，不能移植到其他作品。

口播单位用于粗估时长：一个汉字或一个连续英数词记一个单位。实际用时取决于停顿、切页、重音、现场互动和讲述人语速，最终只能靠真人彩排确定。

## 可蒸馏经验

### 1. 地区变量从开场进入主线

两份稿件都没有把地区当结尾点缀，而是先说明福建即时消费、芜湖政策与产业条件，再解释企业为什么在该地区形成独特经营结果。新稿应在前 30–60 秒完成“企业—地区—矛盾”的绑定。

### 2. 过渡词帮助听众跟上分析

样本使用“首先、接下来、深入分析、不过、当然、基于以上分析”等提示转折。可保留这种口语导航，但应更多使用因果过渡，例如“这项优势同时暴露出……”“因此下一步不是继续扩张，而是……”，避免每页机械说“接下来我们看”。

### 3. 经营证据与结论靠得较近

样本常在主张后立即给数字或案例，再解释其经营意义。这比先念大量背景、最后才下结论更适合路演。新稿固定采用“结论 → 证据 → 含义 → 过渡”。

### 4. 成功经验、瓶颈和建议形成完整弧线

两份稿都先解释企业为何成功，再指出扩张、供应链、人才、产品、物流或品牌问题，最后给出行动建议。新稿继续保留“成功机制—边界—瓶颈—根因—行动”的双线结构。

### 5. 结尾回到行业与地区价值

样本最后都把企业案例提升到区域流通业的启示。新版结尾仍需回答研究问题和复制边界，但避免“必然结果、确保真实、极强可复制”等超出证据的权威断言。

## 不应继承的问题

1. **时长不稳定**：三只松鼠稿按常见语速明显超过 10 分钟；朴朴稿虽然较短，也未记录切页、停顿和实测。
2. **数字过载**：部分段落同时口播 8–18 个数字，听众难以记住结论。每页只选 1–2 个锚点数字，其余留在画面。
3. **朗读表号**：朴朴稿 17 次口播“表/图编号”。现场应指向画面并解释含义，不念报告内部编号。
4. **没有逐页绑定**：两份稿都以长段落呈现，没有 PPT 页码、页面停留时间、来源定位或切页提示。
5. **没有舞台与应急层**：没有停顿、指图、交接、设备异常和超时删减设计。
6. **缺少证据边界**：方法、样本、反证和局限口播不足，容易把相关关系说成因果。
7. **没有多人协作样本**：两份稿均按单人连续陈述写作，不能据此推导多人交接经验；多人方案须另按完整叙事段落分工。
8. **纯报告语言偏多**：如“极具代表性、必然结果、绝佳舞台”等书面判断，应改为可由证据支持的口语表达。

## 蒸馏后的写作主线

```text
30秒内给矛盾与判断
  → 地区/企业/方法证据
  → 五维经营与成功机制
  → 瓶颈、根因与优先级
  → 镜像行动包、实施与风险
  → 回答研究问题和行业边界
```

样本提供的是表达经验而非事实授权。任何数字、案例或结论都必须回到当前项目已确认的 PPT 与报告。
