## 2. 年报数据规则

### 2.1 来源与口径

- 优先采用交易所、监管披露平台或企业投资者关系页面的完整年报；保存报告名称、年度、发布日期、访问日期、URL/文件和精确页码。
- 同一序列必须统一合并范围、会计年度、币种和单位。发生会计政策、业务剥离、并购重述或口径变化时，保留原值、调整值和调整理由。
- 集团数据只能描述集团。年报没有目标省市数据时，不得把集团收入、利润、门店或市场份额写成当地结果。
- 年报中的管理层展望、行业排名和市场份额陈述仍需核对其引用来源、市场定义和统计期间；宣传性表述不等于审计数据。
- 私营企业没有公开年报时，要求用户提供经核验的审计报告或企业正式经营数据。若无法取得，不得虚构年报口径；应建议补数或更换可取证企业。

### 2.2 默认指标池

按企业实际披露选择，不要求机械凑齐：营业收入、归母/净利润、经营活动现金流、毛利或毛利率、期间费用、存货与周转、应收/应付、资本性投入、门店/网点/仓库、会员/客户、订单/交易、分部/地区/渠道收入、数字化投入及与核心命题直接相关的运营指标。

“详细”指口径完整、可比较、可追溯，而不是数字越多越好。每个进入正文的数字都应回答：它支持哪个判断、与什么基准比较、其边界是什么。

### 2.3 B01 默认图表

- 图3-1：研究框架图；
- 图/表4-1：连续3—5年关键财务与经营指标总览；
- 图4-2：收入/业务/渠道/地区构成图，或在年报未披露构成时改为可核验经营网络图；
- 图4-3、图4-4：两种入选模型各自的结果图或关键诊断图；
- 附录：完整变量表、公式、模型诊断、稳健性/敏感性结果和代码路径。

每图必须标明企业、期间、单位、合并范围、来源与页码/表号、计算口径、样本量（如适用）和证据ID。少量离散年度用分组柱、斜率图、KPI表或组合表，不把3个年度点强画成连续趋势线。

## 3. 四类模型的可行性门槛

### 3.1 市场份额模型 `market_share`

**适合回答**：企业在特定地区、品类、渠道和期间的销售规模占同口径市场总量的比例如何变化。

**最低数据**：企业分子与市场分母必须属于同一品类、地区、渠道、期间、含税/不含税和计量单位。分子可来自年报；分母通常还需要政府统计、行业协会或披露方法的专业数据库。年报直接引用份额时，要同时记录其第三方来源和定义。

**基本计算**：`市场份额 = 企业同口径销售额（或销量）/ 市场同口径总销售额（或销量）`。口径不完全一致时只能称“可比口径占比”或“代理份额”，不能写成真实市场份额。

**推荐图**：份额时间序列、企业与可比企业份额条形图、分子—分母口径表。禁止只用企业收入除以模糊的“行业规模”。

### 3.2 协同效应模型 `synergy`

**适合回答**：并购、业务整合、渠道协同、仓网共享、品牌联动或供应链合并后，收入、成本、周转或覆盖是否出现超出独立发展基准的增量。

**最低数据**：明确协同事件/动作、受影响业务、事件前后窗口、结果指标，以及“若未协同会怎样”的可解释反事实。只有管理层声称“产生协同”，没有基准和结果数据时不能称为模型结果。

**估计对象**：先定义收入协同、成本协同或效率协同，不存在一个可套用所有案例的统一“协同效应公式”。示例：`收入协同 = 实际合并后收入 - 独立发展反事实收入`；`成本协同 = 独立发展反事实成本 - 实际合并后成本`。反事实构造及假设必须公开。

**推荐图**：实际值—反事实桥接图、协同贡献瀑布图、事件前后同口径指标图。没有可信反事实时降级为“协同迹象的描述性分析”。

### 3.3 文化溢价双重差分 `did_cultural_premium`

**适合回答**：某项可识别的文化元素、联名、地域文化策略或文化事件，是否使处理组相对可比对照组产生额外价格、销量、毛利、客单或品牌偏好变化。

**最低数据**：处理组、对照组、明确处理时点、至少处理前后观察、稳定且可解释的结果变量；优先使用门店×期间、商品×期间或地区×期间面板。企业合并年报的一条年度序列通常不够。必须定义“文化溢价”究竟是价格溢价、销量提升、毛利变化还是其他可观测结果。

**强制诊断**：处理前趋势/事件研究、组间可比性、无提前反应、同期其他冲击、标准误与聚类层级、处理时点不一致时的估计方法。不能通过平行趋势或识别审查时，只能报告相关性，不得使用“导致”“提升了”等因果措辞。

**推荐图**：处理组/对照组处理前后趋势、事件研究系数与置信区间、安慰剂或稳健性图。多期或错位处理应避免机械套用简单双向固定效应。

方法依据：Callaway 与 Sant’Anna 的多期 DID 研究强调处理时点、条件平行趋势和异质效应；Bertrand、Duflo 与 Mullainathan 提醒关注 DID 的序列相关与推断问题。见 [Callaway & Sant’Anna (2021)](https://doi.org/10.1016/j.jeconom.2020.12.001) 与 [Bertrand et al. (2004)](https://doi.org/10.1162/003355304772839588)。

### 3.4 数字化投入效率 DEA‑Tobit `dea_tobit`

**适合回答**：多个可比门店、地区、分部、年份或企业作为决策单元时，数字化投入转化为经营产出的相对效率如何，以及哪些外部/组织因素与效率差异相关。

**最低数据**：足够数量且技术环境可比的决策单元（DMU）；清晰的投入、产出、方向与规模报酬假设；第二阶段解释变量及其理论依据。单一企业少数年度的合并年报通常不足。样本量必须相对投入/产出维度充足，并报告采用的样本充分性规则，不得通过增加指标制造“高级模型”。

**强制诊断**：异常值、零/负值、投入产出方向、DMU 可比性、效率分布、模型设定敏感性。第二阶段不能把第一阶段估计效率当作无误差观测值机械做普通 Tobit；须说明偏差校正、Bootstrap 或其他一致推断方案，并把朴素 Tobit 至少降为敏感性分析。

**推荐图**：效率分布、DMU 效率排名与置信区间、投入—产出前沿、第二阶段边际效应图。

方法依据：DEA 的经典定义来自 [Charnes, Cooper & Rhodes (1978)](https://doi.org/10.1016/0377-2217(78)90138-8)；两阶段推断须注意 [Simar & Wilson (2007)](https://doi.org/10.1016/j.jeconom.2005.07.009) 对朴素第二阶段回归和不恰当 Bootstrap 的方法警告。

## 4. 双模型选择规则

对四类候选分别标记：

- `READY`：研究问题、变量、样本、口径、识别/反事实、代码和诊断均可落实；
- `CONDITIONAL`：模型可能适用，但仍缺明确字段或关键诊断；
- `BLOCKED`：核心数据或识别条件不存在；
- `NOT_RELEVANT`：不能回答本报告的中心问题。

只从 `READY` 中选且只选两类。优先选能分别解释“企业位置/结果”和“机制/效率”的互补方法，不以复杂程度排序。若 `READY` 少于两类，将状态设为 `MODEL_SELECTION_BLOCKED`，列出最小补数清单、可取得来源和可替代研究设计；不得用模拟数据、插值、模型记忆或未经验证的代理变量凑齐两类。

使用 `assets/empirical-model-plan-template.json` 建立计划并运行：

```bash
python3 scripts/validate_empirical_model_plan.py path/to/empirical-model-plan.json
```

只有内部校验通过后，才可把模型名称、估计结果和图表写入 B01。读者正文不得显示 `PASS/FAIL`、`READY/BLOCKED` 或其他内部状态；不满足条件时先补数或调整设计，不输出“正文完成稿”。

## 5. 内部可复现程序与图表契约

内部分析文件固定包含：

1. `tl;dr`（在执行结果确认后最后填写）；
2. 研究问题、估计对象与两模型选择理由；
3. 年报及外部数据清单、证据ID和精确定位；
4. 数据清洗、单位/币种/合并范围/期间对齐；
5. 描述性统计和缺失/异常/可比性检查；
6. 模型A：公式、变量、假设、估计、诊断、结果图；
7. 模型B：公式、变量、假设、估计、诊断、结果图；
8. 交叉验证、稳健性/敏感性和替代解释；
9. 可进入正文的结论、不可外推范围和导出文件表。

所有参数、日期、随机种子（如适用）和输入路径集中在顶部；不手工改输出数字。导出的图表保留确定性文件名、生成时间和数据版本。运行后复核图形尺度、分母、单位、样本量、置信区间、标签与来源；未经执行的程序、失败的诊断或空白图不得进入 Word。进入读者稿时只保留研究方法、样本、变量、结果、诊断和自然语言边界，不写程序或生产过程。
