## 1. 样本范围与使用边界

本观察来自用户 Obsidian Vault 中标注为“国一计划书”的 11 份 PDF，覆盖京东北京仓配、沈阳副食冷链、德百数字化、三只松鼠芜湖、苏果南京、蜜雪冰城河南、瑞幸山东、天津港物流、汇嘉时代新疆、朴朴福建和谊品重庆。篇幅为 41–161 页，中位数 70 页。

这些作品用于识别获奖材料的结构倾向，不是官方模板，也不证明其中每个数字或来源真实可靠。只迁移论证结构、章节功能和呈现方式；不得复制原文、事实、数据、图表、标题或未经核验的内部资料。

## 3. 各模块正文共性

| 模块 | 国一样本中反复出现的正文内容 | 本技能的升级写法 |
|---|---|---|
| 概要 | 地区变化、案例价值、研究方法、主要发现和建议 | 用一页回答“什么矛盾—什么证据—什么机制—做什么—如何验证” |
| 引言 | 行业与地区背景、选题缘由、问题、方法、研究框架、创新 | 明确决策对象、口径、假设、数据边界；不提前写未经验证的结果 |
| 案例简介 | 企业历程、业务结构、规模、区域布局、关键事件 | 只保留能解释成功机制或阶段瓶颈的事实，并给证据 ID |
| 外部分析 | 政策、经济、社会文化、技术、竞争、顾客和地区差异 | 每项外部变化必须落到收入、成本、时效、周转、服务或扩张机制 |
| 内部分析 | 战略资源、组织能力、供应链、运营、营销、产品和财务 | 围绕价值链与经营结果解释能力、约束和同口径差距 |
| 经营模式 | 客户、价值主张、渠道、收入成本、关键活动、伙伴和资源 | 找到价值创造点、价值泄漏点及地区适配边界，避免画布复述 |
| 地区专题 | 门店/网点/仓配布局、商圈/客群、地区政策与竞品 | 建立全国/目标省市/样本点三级比较，把地区性作为因果变量 |
| 瓶颈 | 市场、区域扩张、供应链、技术、品牌、组织等挑战 | 对每项写症状、差距、直接原因、结构根因、影响、反证和优先级 |
| 方案 | 企业建议、解决方案、战略路径和行业借鉴 | 与根因镜像，补责任、资源、节奏、KPI、试点、停止和回滚条件 |
| 结论与启示 | 研究发现、企业建议、行业启示、局限与展望 | 逐题作答，区分案例结论、可迁移机制、适用条件和不可复制条件 |
| 附录与参考 | 问卷、访谈、数据说明、补充图表和资料 | 提供样本、清洗、编码、公式、证据台账和可访问来源，支持复核 |

## 4. 跨作品因果结构

11 份作品虽然业态不同，但主体普遍围绕：

```text
概要
  → 引言/问题提出/方法
  → 案例企业与地区布局
  → 内部资源、能力、运营与财务
  → 外部政策、需求与本地竞争
  → 商业模式/经营机制
  → 发展瓶颈
  → 对策、结论与行业启示
  → 问卷、访谈、数据与参考资料
```

强作品会再增加一层因果主线：

```text
企业过去为何成功
  → 地区/行业/企业阶段发生什么变化
  → 原有优势为何出现错配
  → 哪些指标或行为证明瓶颈
  → 哪些行动直接改变机制
  → 如何试点、评价和推广
```

## 5. 可迁移的高分写法

### 5.1 把地区性写成因果变量

不只证明“企业在本地有门店”，而要分析地形、人口、商圈、消费文化、政策、产业、物流半径和竞争密度如何改变企业的收入、成本、时效、库存、服务或扩张模型。新疆南北疆、南京多中心商圈、山东城市层级、重庆山地物流和沈阳寒冷/老龄化均属于这种写法。

### 5.2 用一个经营矛盾统领全文

优秀概要会直接提出 1–2 个决策问题，例如空间覆盖与转化失衡、区域扩张与单店盈利适配、技术专利与场景落地脱节、数字化投入与组织吸收能力不匹配。后续章节只解释该矛盾，不写无关企业百科。

### 5.3 双线呈现“优势机制”和“阶段瓶颈”

先说明企业凭什么成功，再说明环境变化后为什么同一机制产生边际递减或新约束。这样瓶颈不是突兀的负面清单，方案也不是泛泛“加强管理”。

### 5.4 方法与数据服务研究问题

作品常见材料包括年报/财务、企业运营数据、政府统计、问卷、访谈、平台评论、GIS/POI、价格与竞品观察。高价值写法是为每个问题指定证据并交叉验证，而不是把“混合研究、情感分析、GIS、大数据”当装饰词。

### 5.5 瓶颈和方案镜像命名

苏果样本的“空间错配—空间重构、技术债务—技术跃迁、用户断层—用户运营、组织僵化—组织变革”体现了清晰映射。沈阳副食样本也采用“装备/数据/渠道/政策—技术升级/数据中台/渠道融合/模式创新”的对应结构。

### 5.6 图表承担判断

常见有效图表包括：地区差距、门店/网点布局、商业模式或价值链、财务趋势、竞争矩阵、样本结构、瓶颈差距、试点前后、实施路线和敏感性。图表必须有来源、期间、地区、口径、单位和一句解释；装饰性流程图不能替代证据。

### 5.7 附录用于可复核，而不是堆材料

有效附录包含研究工具、样本结构、清洗规则、访谈摘要、原始数据表、计算模型和来源指引。正文引用附录编号，使评委能追溯方法和数字。

## 6. 不同业态的分析重点

| 业态 | 优先分析的经营链 | 常用关键指标/代理 |
|---|---|---|
| 区域零售/商超 | 商圈—门店—客群—品类—库存—会员—到家 | 覆盖、客流、转化、客单、坪效、周转、损耗、复购 |
| 生鲜/即时零售 | 采购—仓网—预测—拣配—履约—售后 | 直采占比、缺货、损耗、时效、履约成本、订单密度 |
| 餐饮/连锁加盟 | 产品—定价—供应链—门店密度—加盟商经济—品牌 | 单店盈亏、出杯/翻台、原料成本、闭店、复购、加盟回收期 |
| 港口/物流/冷链 | 节点—线路—仓储—调度—协同—风险 | 吞吐、库容、利用率、周转、时效、空驶、破损、单位成本 |
| 平台/电商 | 流量—转化—履约—服务—留存—单位经济 | 获客、转化、复购、订单、配送时效、履约成本、贡献毛利 |

| 福建朴朴 | 前置仓、供应链、人力和盈利模式覆盖细，附录有问卷访谈 | 方法说明过晚、部分建议偏泛，应前置研究设计和方案测量 |
| 重庆谊品 | 经典结构紧凑，供应链/成本/竞争/口碑与建议对应 | SWOT/PEST/五力容易变成清单，方案需补责任、预算和验证 |

## 8. 固定三级框架的蒸馏结果

固定框架把 11 份作品反复出现的功能与官方最低模块合并为：目录、概要、引言、案例简介、企业内部分析、企业外部分析、企业经营模式、发展瓶颈、经营优化方案、结论与启示、附录及参考资料。

- **内部—外部—模式分章**：11/11 均有内部经营和外部地区功能，10/11 有经营/商业模式专章，因此三章分别负责企业能力结果、环境竞争传导和价值创造机制，避免把所有框架堆在一个大章。
- **五维精准落位**：企业战略、运营管理和财务状况分别固定在5.1、5.2、5.3；市场竞争进入6.3；商业模式进入7.1。内部分析只保留三项核心二级标题，资源组织并入战略，产品客户和供应履约并入运营。
- **双线因果**：案例简介与第 5—7 章先解释企业过去为何成功，再解释地区/行业/阶段变化为何使原有优势出现错配。
- **前部高密度**：国一样本中的企业史、背景和方法篇幅差异很大，本Skill压缩无关叙述，但要求引言配置研究框架图、案例简介用年报数字与程序化图表建立证据密度；完整模型过程放Notebook和附录，把正文篇幅留给经营分析、瓶颈和方案。
- **2—4 项瓶颈**：11/11 都有挑战功能，稳定做法是只保留少数核心约束。每个二级标题直接写“什么问题造成什么后果”，三级再说明表现、原因和影响。
- **方案独立成章**：方案功能在样本中高频出现且位置不一。本Skill固定独立章，并让每个二级标题直接写“改善什么结果、采用什么做法”，再检查具体动作、执行安排和验证条件。
- **三级施工说明**：每个三级标题下用 2—3 行说明准备分析什么、需要何种证据、有哪些边界，防止目录只有名词而没有论证任务。

这套结构是对样本共性的工程化蒸馏，不是官方唯一模板。任何案例事实、数字、结论和内部信息仍须来自本项目证据台账。

## 9. 不得继承的风险

1. **框架堆砌**：同一事实重复放进 PESTEL、SWOT、五力和画布，却没有新增判断。
2. **精确但不可追溯**：用“企业内部报告”“课题组统计”支撑大量精确数字，却无文件、样本、口径或计算过程。
3. **把计划写成结果**：尚未开展的访谈、问卷、系统建设或试点被写成已完成和已提升。
4. **全国数据冒充地区表现**：集团营收、全国门店或行业平均不能直接证明目标地区瓶颈。
5. **目录与正文不一致**：地区名称、章节编号、企业名称、样本量和年份前后冲突。
6. **建议口号化**：只写数字化、加强合作、提升服务，没有对象、动作、责任、成本、KPI和回滚。
7. **篇幅虚胖**：长篇企业史、政策罗列和逐项框架解释挤压真正的机制分析。
8. **结论新增信息**：结论出现正文没有论证的数字、方案或行业推广判断。

使用国一样本时执行“学结构、不借数据；学因果、不抄标题；学图表功能、不复制图表”的原则。
