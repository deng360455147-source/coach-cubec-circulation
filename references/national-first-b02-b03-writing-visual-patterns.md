# B02/B03 国一样本正文与图表蒸馏规范

本规范只适用于已确认框架后的 B02（第5—7章）和 B03（第8—11章）。固定章节和三级标题以框架确认单为准，本文件不改变目录。目标是把11份国一样本中较稳定的自然叙述、数据剖析和多样视觉语法转化为可执行规则，同时避免复制原文、数据、图表、配色成品、边框、吉祥物或水印。

## 1. 样本观察与边界

11份样本覆盖零售、生鲜、即时零售、餐饮加盟、物流、港口和冷链。10份可提取文字的PDF中识别到约221个图题和243个表题；另1份图像型PDF经逐页缩略图复核，也持续使用数据表、柱形/趋势、雷达、桥接和现场图片。该计数受PDF编码影响，只用于说明样本具有较高图表密度，不是完整审计结果。

样本较稳定的共同点是：

- 每一大章都用企业或目标地区的具体经营事实展开，不停留在模型定义；
- 表格保存精确值、口径和对标对象，图形突出趋势、差距、结构或机制；
- 同一作品通常保持一个主色和统一字体，但在表格、趋势、对标、热力、矩阵、流程、地图和路线图之间切换；
- 瓶颈章节常从可观察差距切入，再追到地区场景、流程环节或组织机制；
- 方案章节与瓶颈镜像，常用步骤表、实施路径、阶段路线和指标对比收束。

样本中的精确数字、内部报告、访谈和“试点成效”不自动可信。正文只能使用本项目已核验来源；国一样本只提供写法和视觉功能提示。

## 2. 自然语言与论证节奏

### 2.1 小节不是固定机器句式

每个三级小节用3—5个自然段完成一个分析任务，可在以下四种推进方式中选择最适配的一种，不要所有小节都套同一串连接词。

| 推进方式 | 自然段顺序 | 适用内容 |
|---|---|---|
| 对比驱动 | 现状判断 → 本企业数据 → 同口径对标 → 差距原因 → 经营影响 | 财务、效率、竞争、地区差距 |
| 流程驱动 | 业务场景 → 流程节点 → 数据/时间/成本 → 卡点传导 → 改善杠杆 | 采购、仓配、履约、服务、协同 |
| 场景驱动 | 地区/门店/客群场景 → 可观察现象 → 数据交叉验证 → 机制解释 → 适用边界 | 消费者、商圈、城市层级、本地化 |
| 诊断驱动 | 症状 → 基线/标杆 → 直接原因 → 结构根因及反证 → 对结果的影响 | 第8章瓶颈、风险与错配 |

正文首段直接交代“当前呈现什么特征或矛盾”，但语气应像正常经营分析，不使用连续口号式结论。随后用数据把判断落地，再用具体地区、品类、门店、路线、渠道或客群场景解释为什么会发生。段末自然引向下一问题，例如由资源差距转向运营结果、由外部变化转向模式适配、由瓶颈转向方案杠杆。

### 2.2 常用自然连接

可按语义使用“从……看”“具体来看”“与……相比”“进一步拆分后”“这一差距主要体现在”“在目标地区，该机制表现为”“值得注意的是”“由此可见”“但现有资料尚不足以说明”等连接。不得机械地让每段都以“数据显示”或“综上所述”开头。

### 2.3 数据进入句子的方式

- 先给对象、期间和口径，再给数值；同比、占比、百分点和倍数不得混写。
- 一段保留1—3个锚点数值，其余精确值进入表格，避免正文变成数字清单。
- 对比优先写成“本企业—地区标杆—行业基准”或“全国—目标地区—样本点”，并说明可比范围。
- 先描述事实，再解释机制。资料只能证明相关关系时，不使用“导致”“验证了”“显著提升”等因果词。
- 没有企业地区级数据时，明确集团数据的用途和边界，不把集团结果平移到目标地区。

### 2.4 避免两种极端

一端是生硬的咨询模板，如“结论—证据—机制—含义—边界”逐字显露在正文；另一端是样本中偶见的比喻、宣传口吻和未经证实的精确成效。成稿应保留案例叙事的可读性，但删除“如同精密机器”“滚雪球式扩张”“形成强大护城河”等夸张修辞，除非是被引用对象的原话且有必要。

## 3. B02第5—7章写法

### 3.1 第5章企业内部分析

第5章回答“企业过去凭什么形成经营结果，以及内部能力在哪些环节开始承压”。现有5.1、5.2、5.3标题不变。

- **5.1企业战略**：从战略选择落到资源配置、组织安排和地区重点。不要只复述愿景；用投入、网点、人员、业务结构、阶段事件或地区优先级证明战略实际落点。
- **5.2运营管理**：沿商品、客户、采购、供应、仓储、配送、服务等真实链路展开。用时效、周转、损耗、缺货、客诉、履约成本、转化或复购等指标说明结果，并解释卡点如何在流程中传导。
- **5.3财务状况**：先统一合并范围、币种、期间与公式，再分析增长质量、成本结构、现金周转和资本效率。地区财务不可得时，只使用可核验代理指标，并把不能推出的结论写清楚。

第5章每个三级小节至少映射一张数据表或分析图；全章至少包含两张数值表、一张趋势/组合图、一张内部效率对标图和一张能力或流程图。

### 3.2 第6章企业外部分析

第6章回答“目标地区发生了什么变化，以及这些变化通过什么渠道影响企业”。不能把PEST、五力或政策条目写成百科清单。

- **6.1宏观与地区环境**：政策、人口、收入、交通、地理和技术条件必须落到需求、成本、时效、门店密度、库存或服务半径。
- **6.2行业与市场演进**：写清行业阶段、渠道迁移、客群和场景变化，再判断企业现有能力是否匹配。
- **6.3市场竞争**：竞品集合必须同地区、同客群、同期间、同业务口径；比较价格、覆盖、产品、服务、履约或效率时保留数据来源和分母。

第6章每个三级小节至少映射一张数据表或分析图；全章至少包含两张数值表、一张行业趋势或结构图、一张竞争对标图和一张消费者洞察图。取得合格坐标或行政层级字段时再增加地区地图/空间热力，否则使用地区对标表和节点传导图；只有存在合格文本语料时才使用词云。

### 3.3 第7章企业经营模式

第7章回答“价值如何创造、交付和获取，哪些环节发生价值泄漏，以及全国模式在目标地区能否复制”。商业模式画布只能作为导航，不能代替分析。

- **7.1商业模式**：连接顾客、场景、渠道、关系、收入、成本和伙伴，写出各要素之间的因果接口。
- **7.2流通价值链与经营机制**：同时追踪商品流、信息流和资金流，用时间、成本、转化、周转或损耗展示价值创造与泄漏。
- **7.3地区适配与扩张机制**：比较全国标准与地方接口，说明哪些动作可复制、哪些需要改造、哪些条件缺失时不能扩张。

第7章每个三级小节至少映射一张数据表或分析图；全章至少包含两张数值表、一张商业模式/价值链图、一张三流协同图、一张地区适配热力或差距矩阵和一张扩张边界图。

## 4. B03第8—11章写法

### 4.1 第8章发展瓶颈

第8章只保留2—4项已由B02证明的核心瓶颈。每项采用“结果型二级标题 + 表现/原因/影响三级结构”，标题不变更规则。

每项瓶颈至少配置：

1. 一张症状或差距数据表，列出对象、基线、标杆、差距、期间和来源；
2. 一张诊断图，可从排序柱、帕累托、趋势、热力、地区地图、评论词频或组合图中选择；
3. 一张机制图，用根因链、驱动树、价值泄漏图或流程卡点说明传导；
4. 至少两类独立证据，其中一类为目标地区一手证据；同时写反证和替代解释。

叙述顺序优先为“差距有多大—集中在哪里—为什么发生—影响哪个经营结果”，避免先宣布根因再寻找数据。

### 4.2 第9章经营优化方案

第9章与第8章逐项镜像。每项方案至少配置：

1. 一张动作机制或改造前后流程图；
2. 一张分阶段路线图、责任泳道或甘特式计划；
3. 一张实施数据表，列明责任、时间、资源/预算、依赖、KPI、频率、触发器和回滚；
4. 一张评价图，可使用情景组合图、敏感性图、指标卡、风险热力或阶段漏斗，但不得把预测写成已实现结果。

正文写“具体动作如何改变第8章中的根因”，而不是再次描述问题。没有基线时使用范围、试点和停止条件，不承诺精确提升比例。

内部逐项核对“8.n瓶颈—8.n.2根因—9.n.1动作—9.n.2责任/时间/预算—9.n.3同口径KPI/触发/回滚”。转化率、周转、等待、损耗、复购、收入、利润、节省、投资回报、回收期和推广覆盖等未来数值，只能写成目标范围、情景测算或待试点验证；预算是计划输入，KPI阈值是决策线，均不是已取得结果。

### 4.3 第10章结论与启示

逐项回答研究问题，归纳“优势—错配—瓶颈—方案”的证据链。至少使用问题—结论—证据导航图和可迁移条件矩阵各一张；不得新增正文未出现的数据、模型结论或方案收益。

### 4.4 第11章附录及参考资料

六个既定二级标题保持不变。企业数据概览使用同口径总表；问卷采用专业母版，给出知情说明、筛选/跳题、最近行为、构念映射、预测试、清洗、变量编码及真实样本结构；访谈按角色给正式纲要、参与/录音/材料同意、匿名编号、反证和主题代码本；竞品/现场记录保留时间、地点、对象和照片来源；补充图表保留数据、公式、文本清洗、停用词、模型诊断与地区对标。参考文献采用现行GB/T 7714—2025顺序编码制的期刊式普通段落列表与悬挂缩进，禁止表格排版。

## 5. 图表组合与视觉风格

### 5.1 整体统一，图形多样

参考样本的稳定视觉语法，但不复刻其成品：白色或近白页面、深色正文、一个主强调色、一个辅助强调色、浅色表头/分区底、清晰图题和紧邻来源。不得复制样本边框、吉祥物、水印、封面或独特图形。

结构型图片使用Excalidraw式“视觉论证”：分流用扇出、汇聚用收敛、顺序用时间轴、层级用树、反馈用循环、前后改造用并列对照，避免整页等宽卡片。图题只作为Word外置题注，图片内不放图号、题名或来源全文；每张图片前先用正文交代分析目的与重点读数。图内凡有文字均按最终Word嵌入尺寸统一为12pt，不能用缩字解决信息过密。imagegen只为适配的无文字位图素材提供辅助，不生成数据图、精确中文标签或企业事实。

同一批次至少使用下列视觉家族中的5类，B02建议6类以上：

- 数据表/指标卡；
- 趋势与组合；
- 比较与排序；
- 构成与分布；
- 矩阵、热力与地区地图；
- 文本挖掘；
- 关系、分解与价值泄漏；
- 流程、机制与路线图。

单一视觉家族不得超过本批全部合格视觉的40%；不得连续使用两张同一变体、同一版式的图。折线图、柱状图、热力图、词云图、组合图和数据表均须在图表地图中做适用性审查：有数据则使用，无数据则写明原因并换成诚实的替代形式。

### 5.2 页面版式轮换

在统一页眉页脚、字体、字号和主色基础上，至少轮换三种版式：

- 全宽数值表或全宽地图；
- 左文右图；
- 左图右文；
- 表格+图形成对；
- 两张同口径小多图；
- 上图下结论或上结论下路线图；
- 附录证据网格。

版式轮换服务阅读，不追求每页不同。相邻两页如果回答同一问题，可以保持一组视觉节奏；跨章节应改变主要图形家族，避免整批只有蓝色柱状图。

表格作为精确值载体时，所有单元格段落首行缩进为0，文字水平和垂直居中；表题位于表格上方。正文统一1.25倍行距。章节之间由一级标题段前分页，其他位置不插手工分页符。

### 5.3 图表风格模式

在同一基础色板中至少使用三种模式：

| 模式 | 典型用法 | 颜色原则 |
|---|---|---|
| 单主色证据型 | 单序列趋势、排名、基础表 | 主色深浅 + 中性灰 |
| 焦点—背景对比型 | 本企业与竞品/标杆 | 主色突出本企业，背景对象用灰或辅助色 |
| 顺序热力型 | 城市×指标、品类×问题、风险矩阵 | 同一色根由浅到深，缺失值单独标记 |
| 多类别识别型 | 有限品类、渠道、客群构成 | 最多5个明确颜色，超过则Top-N+其他 |
| 正负差异型 | 预算差异、价值泄漏、瀑布/桥接 | 两个非中性色 + 零线/基准线，不默认红绿 |
| 方案路线型 | 流程、泳道、里程碑 | 主色节点、浅色阶段带、深灰依赖线 |

## 6. 特殊图形的数据门槛

- **折线图**：优先8—12个连续观察点；只有3—5个离散年度时改用分组柱、斜率图或表格，不能用平滑曲线制造趋势。
- **柱状图**：至少4个有意义的类别或期间；类别无自然顺序时排序，长标签使用横向条形。
- **热力图**：至少形成3×3同口径矩阵；色阶、缺失值、分母和时间范围必须可见。
- **词云图**：至少100条完成清洗的评论、访谈语句或开放题文本；保留分词词典、停用词表、有效文本量和词频表。词云必须与Top-N词频柱状图或主题编码表成对，不能单独证明情感、满意度或因果。
- **组合图**：两个指标必须共享对象、期间和业务逻辑；单位不同则清楚标注轴和尺度。若双轴会误导，改用上下对齐小多图。
- **雷达图**：每个维度必须有公开评分锚点、同一量纲和计算依据；没有锚点时改用热力矩阵或点图。
- **地图/空间热力**：保留坐标/行政层级、统计口径、时间和空间范围；点位缺失不得用插值伪装覆盖。
- **现场/产品图片**：只作经营证据，写明时间、地点、对象和授权/来源；不能替代数据分析。

前向测试已确认以下替代规则：80条清洗评论不足以生成词云，改用Top-N主题词频柱和编码表；4个离散年报年度不足以生成连续趋势线，改用分组柱、斜率图或KPI表；只有12个月门店数据不能声称跨年度同比或长期季节性；没有坐标不做空间热力，没有可加总节点流量不做桑基，没有评分锚点不做雷达，没有同地区同品类同期市场分母不做市场份额图，没有处理/对照面板不做DID或事件研究图。缺少这些条件时，图表地图必须标记 `NOT_APPLICABLE` 并记录替代形式，不得为了通过多样性检查补造字段。

## 7. 批次验收

开写前复制 `assets/report-visual-map-template.json`，逐张记录章节、问题、判断、数据文件、来源、图形家族、具体变体、风格模式和版式。运行：

```bash
python3 scripts/validate_report_visual_map.py path/to/report-visual-map.json
```

验收同时满足：

1. 固定三级标题未改变，每个三级小节有至少一张主视觉或数值表映射；
2. B02每章至少两张数值表，B03每项瓶颈/方案满足本规范的证据组合；
3. B02/B03至少5个视觉家族、3种风格模式和3种页面版式，单一家族占比不超过40%；
4. 折线、柱形、热力、词云、组合和数据表均已审查，未采用项有数据原因与替代方案；
5. 每张图表可回到数据文件和来源定位，图题、单位、期间、地区、样本/分母与来源完整；
6. Word最终逐页清单中的图形家族、风格和版式与图表地图一致，并完成全页渲染复核。
